#
# List of starbase model assets within models/ subdir
#
# Format of each line is:
# starbase-model-file docking-port-file [EASY|HARD [decimation-factor]]
# if the docking-port-file is '!', then there is no dockng port file
# if the docking-port-file is '-', then the docking port file has the
# standard name, for blah.stl will be blah.docking_port.h
#
# The 3rd parameter is the docking difficulty, either EASY or HARD
# EASY means the player is not required to match alignment and speed to dock
# HARD means the player is required to match alignment and speed.
# Some stations (starbase.obj) have docking ports such that matching the
# speed is impossible (would require the player to fly sideways) and so
# EASY mode allows docking to be done successfully.
#
# The 4th parameter is the optional decimation factor for the low poly model
# (an integer >= 1; default is 8).
#
